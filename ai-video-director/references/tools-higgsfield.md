# Higgsfield: discovery, generation and evaluation

## Select by the shot's requirement

Discover the current connector tools. Use read-only model search/recommendation, then inspect the exact model and generation-operation schemas. Check available modes, reference roles/counts, input limits, aspect ratios, duration/resolution combinations, audio and editing/extension behavior. A catalog search result is a candidate list, not an execution contract or performance benchmark.

Compare only a small qualified set. A character route needs identity/reference control; a product mechanism needs geometry/action accuracy; an environment route needs composition/layout control; dialogue needs voice and synchronization. Recommend a representative pilot when the difference matters. Evaluate that pilot against the actual acceptance criteria, not an unrelated demo.

## Reference preparation

Supply clean assets with explicit roles. Use the accepted identity image for identity, a scene frame for composition, an environment reference for layout and motion reference only for intended motion. Check supported combinations and counts. Avoid unrelated character faces, conflicting costumes or multi-panel sheets when the model expects one frame. Use supplied start/end images only if the selected mode supports them.

Attach media through the actual tool mechanism. Verify confirmed media IDs and input accessibility. Do not claim a reference was applied merely because its ID appeared inside prompt prose. For exact logos, diagrams and long copy, prefer controlled finishing when generated output cannot be relied on.

## Quote, execute and recover

When available, follow `cost-aware-media` for quotes, budget reservation, job records and retries. Otherwise obtain a read-only quote for explicit model/mode, duration, resolution, aspect, audio, inputs and count. Distinguish provider credits, subscription allowances and currency. Confirm access/entitlement through the channel being used. A saved monthly preference is not authorization.

Use existing sufficient authorization. If missing, prepare the concrete run and ask only at the affected action. Track the job ID and reconcile ambiguous submissions before any duplicate request. Keep retries within the authorized scope/cap and stop when the acceptance criteria are met. Do not switch from a requested free entitlement to paid generation silently.

## Inspect and deliver

For images, inspect required features and reference fidelity. For video, review action throughout, temporal consistency, contact, camera behavior, native audio and start/end usability. Record failure reasons before retrying. Keep accepted source references, actual settings, job IDs and outputs together. Use the connector's supported display/download mechanism. A retrieved preview or successful job status is not a full quality review.
