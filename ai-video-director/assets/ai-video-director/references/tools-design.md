# Reasoning and design tools

## GPT reasoning / Astra

Use the available reasoning model to organize the brief, investigate options, write scripts/prompts, prepare production code and evaluate evidence. Select image/video generation or application tools separately. Model names do not by themselves establish rendering, playback, browsing or application-control access.

For compact prompts, send the accepted creative facts, current task and relevant reference files. Keep tool schemas/settings in their proper execution fields. Do not repeat the whole production guide on every shot. A text-only handoff must state where the recipient needs actual images, audio or project files.

## Claude Design or another design application

Use when visual exploration, campaign layouts, presentation boards, typography or interactive design review would help. Anthropic's [Claude Design announcement](https://www.anthropic.com/news/claude-design-anthropic-labs), checked 2026-09-19, describes designs, prototypes, slides and marketing visuals. That supports a visual-development role; it does not establish all video-editing or 3D production capabilities.

Verify access and current export formats. Agree canvas size, brand assets, editable layers/components, font availability and handoff destination. A polished board can communicate direction but is not automatically a layered AE composition, Blender scene or production-ready video.

## Portable creative handoff

Provide purpose/audience, exact copy, aspect, style constraints, accepted references and their roles, prohibited changes, required output files and acceptance criteria. If exporting a static frame for a video model, remove irrelevant labels/panels and preserve a clean version. If handing off editable layouts, test font and layer compatibility in the receiving tool.

Keep the workflow open to other tools when they solve a specific requirement. Explain what the new tool contributes and whether the existing set can achieve a simpler version. Do not expand subscriptions or install software without the user's applicable authorization.
