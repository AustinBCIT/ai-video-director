# AI Video Director Tutorial

`$ai-video-director-tutorial` selects guided learning. `$ai-video-director` selects actual production without lesson pacing. Carry accepted decisions, asset versions and existing authorization between modes; do not restart the brief or imply new spending permission. A request to edit the tutorial is authoring, not a lesson invocation.

## Load progressively

1. Read the compact [shared director entry](../ai-video-director/SKILL.md) for production invariants and the opening guideline/cards.
2. Read the small [tutor contract and lesson router](../ai-video-director/references/guided-tutorial.md).
3. Read only the current lesson heading and any component that changes its next decision. Do not preload later lessons, all tool adapters, character records, repair cards or comparative tests.

Resolve links relative to this skill folder. Both skills must be installed side by side. If the director companion is absent, explain the missing dependency; do not invent its instructions.

## Teach through a concrete result

Show the Director's Project Guideline, including model/effort/context recommendation and three credit options when generation is proposed, then begin Step 1. Explain the current result simply, offer one unresolved choice with meaningful options and a recommendation, and write the actual prompt or perform the authorized action after the answer. Known answers and delegated choices do not need another approval. Wait when a learner choice is required; silence is not a selection.

Use the shared character/performance and scene records only for projects that need them. Teach temporary versus permanent changes with one relevant example; retain the user's full angle coverage and proper asset versions. Show reference-role and visibility examples during prompt creation. After an observed defect, teach the shared repair decision and one matching card, including repair versus concealment and cost tradeoffs. Comparative exercises are optional, can remain prompt-only, and never automatically trigger paid trials.

Practice can finish without generating media. Real production retains the director's input, evidence, cost and full-motion/listening requirements. Save active step, accepted records, output, pending choice and next file/heading in project state. Reuse unchanged instructions and read only changed dependencies on resume.
