# AI Video Director

A guided video-production skill for Shorts, ads, drama, short films, educational videos, YouTube content and motion graphics, plus a standalone fill-in Markdown brief.

## Download the complete package

**[Download AI Video Director ZIP](ai-video-director-download.zip?raw=true)**

This ZIP contains the full skill, all reference guides, three worked examples, the fill-in brief and installation instructions. You do not need Git or a GitHub account to download this public package.

## Install in Codex

1. Download the ZIP above and extract it.
2. Open the extracted `ai-video-director-download` folder.
3. Copy its **`ai-video-director` folder** into your personal Codex skills directory:
   - Windows: `%USERPROFILE%\.codex\skills\`
   - macOS / Linux: `~/.codex/skills/`
   - If you use a custom `CODEX_HOME`, use its `skills` directory.
4. Check that the result is `skills/ai-video-director/SKILL.md`, with `assets`, `references` and `agents` alongside it. Keep the complete folder together.
5. Start a new Codex task with:

```text
Use $ai-video-director to help plan my video. Start with the minimum
questions and recommend ways to save tokens and generation credits.
```

Installing the skill does not install creative applications, connect accounts or buy generation credits. It adapts to the tools available to you.

## Use the brief without installing the skill

Open **[video-project-brief.md](video-project-brief.md)**, fill the **Quick core**, and delete optional sections you do not need. Paste or attach the filled file to your preferred reasoning AI. Attach actual reference media when the production tool needs them.

Use `recommend`, `skip`, `default`, `later` or `not applicable` where useful. The guide flags missing information when it matters to the next action.

## Included

- Quick, Standard and Detailed planning paths.
- Scripts, storyboards, shot lists, cinematography, design and continuity.
- Character references using one main face and separate body/costume views.
- Sound, music, readable captions, editing, motion graphics and delivery checks.
- Tool guidance for GPT reasoning, Higgsfield, Blender, Resolve Free, After Effects and Claude Design.
- Savings guidance: compact context, reusable assets, short tests, low-resolution drafts, selective upscaling, proxies and bounded retries.
- Worked examples for a Short, product ad and short film.

References load only when relevant. Optional specialist skills are discovered at handoff; third-party plugins are not bundled.

## Costs and quality

Compare the total draft, upscale and retry cost with direct final-quality generation. Upscaling cannot reliably repair wrong identity, geometry or action. The savings guide explains when each route makes sense.

Model notes are dated observations, not permanent rankings. Changing capabilities, prices and platform requirements should be checked at use. Planning does not automatically authorize spending or publication.

The package contains blank templates and fictional examples, with no account credentials or local project paths. The examples are plans, not rendered or audience-tested videos.
